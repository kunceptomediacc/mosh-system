## Visual regression

Committed locked-state baselines now cover:

- mobile: 375 px
- tablet: 768 px
- desktop: 1440 px

The browser test compares PNG dimensions and pixels, permits at most 0.5% changed pixels, and writes actual/diff artifacts on failure. Missing baselines are a hard failure rather than a silent pass. Baselines are refreshed only when `MOSH_UPDATE_BASELINES=1` is explicitly set.
